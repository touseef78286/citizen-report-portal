# Figma Se Download Karne Ka Complete Guide

## 📥 Different Ways to Download from Figma

### 1. **Individual Assets/Images Download** (سب سے آسان طریقہ)

#### Steps:
1. Figma file میں جائیں
2. جس element/image کو download کرنا ہے، اسے **select** کریں
3. Right sidebar میں **"Export"** section دیکھیں
4. Format select کریں:
   - **PNG** - transparent background کے لیے
   - **JPG** - photos کے لیے
   - **SVG** - icons/vectors کے لیے
   - **PDF** - documents کے لیے
5. **"Export [name]"** button click کریں
6. File automatically download ہو جائے گی

#### Keyboard Shortcut:
- **Mac:** `Cmd + Shift + E`
- **Windows:** `Ctrl + Shift + E`

---

### 2. **Multiple Assets Ek Saath Download**

#### Steps:
1. **Shift** key دباکر multiple items select کریں
   - یا **Cmd/Ctrl + A** سے سب select کریں
2. Right sidebar میں Export section میں سب items نظر آئیں گی
3. ہر item کے لیے format select کریں
4. **"Export"** button click کریں
5. سب files ایک ساتھ download ہو جائیں گی

---

### 3. **Frame/Component Ko Image Ke Taur Par**

#### Steps:
1. Frame یا component select کریں
2. Right sidebar میں **"Export"** section
3. **"+"** button click کریں
4. Format select کریں:
   - **1x, 2x, 3x** - different resolutions
   - **PNG, JPG, SVG, PDF**
5. **"Export [name]"** click کریں

---

### 4. **Entire Page/Design Ko PDF Mein**

#### Method 1: Export as PDF
1. Page یا frame select کریں
2. Menu bar: **File → Export → Export [name] as PDF**
3. Settings adjust کریں (quality, pages)
4. Export کریں

#### Method 2: Print to PDF
1. **File → Print**
2. Print dialog میں "Save as PDF" select کریں
3. Save کریں

---

### 5. **Code Export** (React, CSS, HTML)

#### Steps:
1. Element select کریں
2. Right sidebar میں **"Inspect"** tab کھولیں
3. Code snippets دیکھیں:
   - **CSS** properties
   - **React** components (اگر plugin install ہے)
   - **HTML** structure
4. Copy کریں یا export کریں

#### Plugins for Better Code Export:
- **Figma to React** plugin
- **Figma to HTML/CSS** plugin
- **Anima** plugin

---

### 6. **Figma File Ko Local Save**

#### Figma Desktop App:
1. File open کریں
2. **File → Save local copy**
3. Location select کریں
4. Save کریں

#### Figma Web:
- Figma web automatically cloud میں save کرتا ہے
- Local backup کے لیے export options use کریں

---

### 7. **Design Tokens / Assets Library**

#### Steps:
1. **Assets** panel کھولیں (left sidebar)
2. Components/icons select کریں
3. Export section سے format select کریں
4. Export کریں

---

## ⚙️ Export Settings

### **PNG Settings:**
- **1x** - Normal quality (72 DPI)
- **2x** - High quality (144 DPI)
- **3x** - Very high quality (216 DPI)
- **4x** - Ultra high quality (288 DPI)

### **JPG Settings:**
- Quality: 80-100% (recommended)
- Use for photos/images

### **SVG Settings:**
- Best for icons, logos, illustrations
- Scalable (no quality loss)

### **PDF Settings:**
- Pages: All or specific
- Quality: High
- Include: All layers or flattened

   - `Cmd/Ctrl + Shift + E` - Quick export
   - `Cmd/Ctrl + E` - Export selected

2. **Export Presets:**
   - Export section میں presets save کریں
   - Reuse کریں

3. **Naming:**
   - Export سے پہلے proper naming کریں

## ❓ Common Issues & Solutions

### **Export button نظر نہیں آ رہا:**
- Element select کریں (not just click)
- Right sidebar کھولیں
- Export section expand کریں

### **File download نہیں ہو رہی:**
- Browser settings check کریں
- Pop-up blocker disable کریں
- Different browser try کریں

### **Quality issue:**
- Higher resolution select کریں (2x, 3x)
- PNG use کریں (JPG کی بجائے)
- SVG use کریں (vectors کے لیے)

### **Large file size:**
- JPG use کریں (PNG کی بجائے)
- Resolution کم کریں
- Compression use کریں
